API & indicateurs auto-level

Ces outils utilisent votre clé API personnelle (ci-dessus) pour afficher les niveaux du jour directement sur votre plateforme, sans copier-coller.
TradingView Extension Chrome
  1. Installer l'extension « The Hub — GEX Levels » depuis le Chrome Web Store.
  2. Ouvrir un chart sur TradingView (NQ, ES, SPX ou GOLD).
  3. Cliquer sur l'icône de l'extension et coller votre clé API personnelle ci-dessus.
  4. Les niveaux GEX du jour s'affichent et se mettent à jour automatiquement.
Installer l'extension
Quantower —
  1. Télécharger l'indicateur ci-dessous et le placer dans le dossier des scripts Quantower (Paramètres → Scripts → Indicateurs).
  2. Redémarrer Quantower ou rafraîchir la liste des algos.
  3. Ajouter l'indicateur « GexDash Levels » sur votre chart.
  4. Renseigner votre clé API personnelle dans les paramètres de l'indicateur.
Télécharger
MotiveWave —
  1. Télécharger l'étude ci-dessous et l'importer via Étude → Gérer les études → Importer.
  2. Redémarrer MotiveWave si nécessaire.
  3. Ajouter l'étude « GexDash Levels » sur votre chart.
  4. Renseigner votre clé API personnelle dans les paramètres de l'étude.
